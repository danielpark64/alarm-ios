# 스토어 등록 문구 (9개 언어)

- 파일 이름은 Play Console의 언어 코드. 파일 첫 줄에 같은 문구를 함께 쓸 언어가 적혀 있다.
- 해외용 앱 이름은 **RotaWake**(2026-10-14 확정). 한국어 스토어 제목은 "교대알람(RotaWake)".
  처음 정했던 "ShiftWake"는 같은 이름의 교대근무 알람 앱이 App Store 2개·Play 1개 이미 있어 바꿨다.
- 글자 수 제한: 제목 30, 짧은 설명 80, 전체 설명 4000, 새로운 기능 500.
- 한국 전용 기능(공휴일·음력·반반차·출퇴근 태그 이야기)은 한국어 문구에만 있다.
- 스크린샷은 `../screenshots/i18n-2026-10-14/<언어>/` (1350×2400, 언어별 6장).
- 번역은 원어민 검수를 거치지 않았다. 앱 안 용어(근무조·하루 근무 변경 이름)는 번역 사전과 같은 표기를 썼다.
