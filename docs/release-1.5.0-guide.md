# 1.5.0 (versionCode 10) Play 출시 안내 — 다국어 첫 출시

준비된 자료
- AAB: `~/Desktop/교대알람-1.5.0-vc10.aab`
- 등록 문구(제목·짧은 설명·전체 설명): `store-assets/listings/<언어>.md`
- 출시 노트(전 언어 한 번에 붙여넣기): `store-assets/release-notes-1.5.0.md`
- 스크린샷(언어별 6장, 1350×2400): `store-assets/screenshots/i18n-2026-10-14/<언어>/` (같은 파일이 `~/Desktop/스크린샷/스토어-다국어-2026-10-14/`)
- 대표 이미지(1024×500): `store-assets/feature-graphics/<언어>.png` — `python3 scripts/make-feature-graphic.py "<앱 이름>"`으로 다시 만든다
- 개인정보처리방침: `docs/privacy.html`에 영어판 추가(같은 주소, `#en`)

Play Console에서 할 일(순서대로)
1. **성장 > 스토어 등록정보 > 기본 스토어 등록정보 > 번역 관리 > 직접 번역 추가**에서 언어를 추가한다.
   영어(en-US), 일본어(ja-JP), 중국어 간체(zh-CN), 중국어 번체(zh-TW), 스페인어(es-ES), 프랑스어(fr-FR), 독일어(de-DE), 포르투갈어(pt-BR).
   같은 문구를 쓸 지역 변형(en-GB, es-419, fr-CA, pt-PT, zh-HK)은 원하면 추가한다.
2. 언어마다 **앱 이름 / 간단한 설명 / 자세한 설명**을 해당 `listings/<언어>.md`에서 복사한다. `{{APP}}`는 확정한 이름으로 바꾼다.
3. 언어마다 **휴대전화 스크린샷 6장**(01→06 순서)과 **그래픽 이미지**를 올린다. 한국어 스크린샷도 이번에 새로 찍은 것으로 교체한다(UI 변경).
4. **프로덕션 > 새 버전 만들기**에서 AAB를 올리고 출시 노트를 붙여 넣는다.
5. **정책 > 앱 콘텐츠**: 개인정보처리방침 주소는 그대로. 데이터 보안 답변은 바뀌지 않는다(수집 없음).
6. **프로덕션 > 국가/지역**에서 배포할 나라를 추가한다. 지금 한국만 선택돼 있으면 해외에서는 스토어에 보이지 않는다.
7. 검토 제출. 심사 중에는 다시 제출하지 않는다.

주의
- versionCode 10은 Play에 올리는 순간 소모된다. 올린 뒤 코드를 고치면 11로 다시 빌드한다.
- 번역은 원어민 검수를 거치지 않았다. 출시 후 리뷰에서 어색한 표현이 나오면 `src/i18n/locales/<언어>.ts`와 `store-assets/listings/`를 함께 고친다.
