근무표 공유 시안 — 교대알람 1.6.0

달력 위에 사람마다 창(탭)이 생깁니다. 받은 근무표는 보기만 하고 알람은 울리지 않습니다. 보내기는 카톡 링크 한 줄로 하고, 서버나 가입은 없습니다.

정해 주실 것

아래는 제가 권하는 안입니다. 다르게 하고 싶은 것만 말씀해 주세요.

1. 창 줄의 모양

둥근 칩을 가로로 늘어놓고 많으면 옆으로 밀어 봅니다. 순서는 전체 · 나 · 받은 순서, 맨 끝에 [+ 받는 법] 안내.

권장: 시안 그대로

2. 전체 창 표시

근무 글자 대신 색 점(4개까지 + 나머지 숫자). 글자까지 넣으면 칸이 좁아 읽기 어렵습니다.

권장: 점 · 다른 안: 2명까지만 글자

3. [보내기] 버튼 위치

달력 위 오른쪽(①). 설정 화면에도 같은 항목을 하나 둡니다.

권장: 달력 위 + 설정

4. 자동 이름

이름을 안 지으면 공유1, 공유2… 나중에 창을 길게 눌러 이름·색 바꾸기, 지우기.

권장: 공유1·공유2

5. “다 같이 쉬는 날” 색

내 비번(파랑 테두리)과 헷갈리지 않게 초록 테두리. 기본은 꺼짐.

권장: 초록, 기본 꺼짐

6. 보내는 범위

오늘부터 약 7개월(215일). 링크 한 줄에 들어가는 최대치이고, 세이람과 같은 형식입니다.

권장: 215일

시안의 근무표와 이름(엄마·동생·공유1)은 예시입니다. 실제 앱은 9개 언어로 나오고, 라이트 테마도 같은 배치입니다.
